# Микросервисное приложение на Spring Boot и React для бронирования мероприятий

## Краткое описание функционала

Приложение позволяет админам создавать мероприятия, места на которых другие пользователи могут забронировать.

## Компоненты системы

1. Сервис мероприятий и бронирований (**reservation**). Управляет состоянием мероприятий и бронирований мест.

2. Сервис авторизации и пользователей (**auth**). Позволяет пользователям регистрироваться, аутентифицирует их и авторизует для действий с сервисом мероприятий.

3. Пользовательский интерфейс (**webui**). Графический интерфейс для браузера, позволяющий работать с функционалом приложения.

4. АПИ-Гейтвей (**gateway**). Через него проходят все запросы от интерфейса к сервисам.

5. Сервис уведомлений (**notification**). Управляет отправкой уведомлений пользователям.

Взаимодействие между сервисами происходит по HTTP протоколу, также используется AMQP для передачи сообщений в сервис уведомлений, сам же этот сервис отправляет почту по SMTP.

## Развертывание проекта в dev-среде
№
1. Создайте локальный файл с переменными окружения и переопределите нужные вам переменные

```bash
cp .env .env.local
```

2. Сгенерируйте ssh ключи

```bash
make gen-ssh-keys
```

3. Соберите проект

```bash
make build
```

4. Запустите проект

```bash
make up
```

5. Веб-интерфейс должен быть доступен по адресу http://localhost:${WEBUI_PORT:80}
